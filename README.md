Internship-16-SpaceX
A modern, responsive React application built to explore SpaceX launches, fleet ships, and company history using the SpaceX API v4. This project focuses on high performance, clean code architecture, and advanced React patterns.

🚀 Getting Started
Follow these steps to run the project locally:

Clone the repository:

Bash
git clone https://github.com/YOUR_USERNAME/Internship-16-SpaceX.git
Install dependencies:

Bash
npm install
Run the development server:

Bash
npm run dev
Open in browser:
Navigate to http://localhost:5173.
